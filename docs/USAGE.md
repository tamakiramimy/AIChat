# 使用说明

## 首次配置

开发环境按 [README](../README.md) 的步骤启动前后端。生产环境由管理员配置模型服务和访问地址；浏览器不需要、也不应该填写模型 API 密钥。

打开应用后，系统会在浏览器本地生成一个客户端标识，用于恢复该浏览器的会话列表。清除浏览器站点数据会使本地客户端标识改变。

## 发起聊天

1. 在输入框键入问题或指令并发送。
2. 回复会以流式方式逐段显示；网络中断或停止操作会终止当前生成。
3. 代码块提供复制按钮，表格可横向滚动查看。
4. 从会话列表选择历史对话可继续上下文；新建会话可开始独立对话。

## 图片与文档

使用附件按钮选择图片或以下文档类型：PDF、Word、Excel、PowerPoint、TXT、CSV、Markdown。

- 每个文件最大 20 MB。
- 最多可暂存 5 张图片和 5 个文档。
- 图片会在客户端压缩后上传；扫描型 PDF 和含图文档可能使用视觉模型。
- 视觉模型未启用时，应用会保留可提取的文本并提示无法识别图片内容。

不要上传包含不应交给模型服务处理的密钥、个人信息或受限制文件。历史记录和附件保存在部署端的 SQLite 数据库中，保留时长由部署方管理。

## 语音

- 录音会发送到已配置的 STT 服务并转成文字。
- 单次音频请求最大 10 MB，只接受 WebM、Ogg、MP3 或 WAV。
- AI 回复可发送到已配置的 TTS 服务播放；单次文字输入上限为 10,000 个字符。

如果语音功能失败，确认浏览器已授予麦克风权限，并由管理员检查 STT/TTS 模型端点、模型名和密钥。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 页面无法连接 API | 开发环境确认 `VITE_API_BASE_URL=http://localhost:5000/api`；生产环境确认 Nginx 将 `/api/` 转发到 API。 |
| 浏览器报 CORS 错误 | 确认 `Cors__AllowedOrigins__0` 与浏览器地址完全一致，包含协议且不带路径。 |
| 回复长时间不出现 | 检查模型服务可达性，以及反向代理是否关闭了响应缓冲。 |
| 附件被拒绝 | 检查类型、单个文件大小和附件数量；服务端会以实际解码后的数据大小为准。 |
| 启动后没有历史 | 确认 `Data/` 是持久化目录，且部署没有替换或删除 SQLite 数据库。 |
